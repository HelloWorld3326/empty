# 一期接口清单 · 65 个 Endpoint

> 这是 `contracts/openapi.yaml` 的**先行草案**，用于核对范围与估算。

> 列表接口统一支持 `page` / `page_size` / `keyword`，统一返回 `{ items, total, page, page_size }`。

## 三个已知的设计取舍

1. **资源挂载用全量替换**（#24 `PUT`）而不是逐条增删。前端一次提交全部挂载关系，
   后端整体覆盖。少四个接口，且天然避免并发下的挂载状态不一致。
2. **配置变更记录不埋点**（#65）。由 `version_no=0` 与 `current_version_no` 两份
   JSONB 做 diff 实时生成，因此不需要在每个写接口里记录变更。
3. **即时测试复用运行接口**（#25–27）。`mode=test` 与 `mode=chat` 走同一条链路，
   区别只在于 test 不写 `conversation` / `message`。这让「即时测试」不需要独立接口。
