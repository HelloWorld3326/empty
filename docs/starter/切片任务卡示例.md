# 给 AI 下任务的模板（垂直切片任务卡）

把这张卡整段贴给 AI 编码助手。四个部分缺一不可——缺了 AI 就会自己编。

---

## 示例：S12 资源·模型

### 1. 切片范围

实现"资源中心 - 模型"这一整个垂直切片，从数据库到 API 到页面。
参考 `docs/一期技术方案与任务拆解.md` 第 7 节的 S12。

### 2. 已定的契约（不许改，对不上就来问我）

**表**：`contracts/schema.sql` 里的 `resource_model`

**接口**：`contracts/openapi.yaml` 里 `resources·models` 这一组的 6 个
- `GET  /api/resources/models` 列表（支持 model_type 过滤、分页、搜索）
- `GET  /api/resources/models/available` 可接入模型清单
- `POST /api/resources/models` 接入模型（支持多选批量）
- `PATCH /api/resources/models/{id}` 启用 / 停用
- `DELETE /api/resources/models/{id}` 删除（返回引用影响）
- `POST /api/resources/models/{id}/test` 连通性测试

**错误码**：`contracts/errors.md`

### 3. 验收标准

- [ ] 能接入一个阿里云百炼模型，填 base_url 和 api_key 后保存成功
- [ ] `api_key` 在数据库里是密文，接口返回时是 `sk-****abcd`
- [ ] 点"测试连接"会真的发一次请求，超时 / 鉴权失败 / 模型不存在三种情况
      分别返回不同的错误码和人话提示
- [ ] 删除一个被智能体引用的模型时，确认弹窗要显示"被 N 个智能体引用"
- [ ] 列表页支持按大模型 / ASR / TTS / Embedding 切换分类
- [ ] 停用的模型不出现在智能体配置页的模型下拉框里
- [ ] 后端有单元测试覆盖：加密解密、连通性测试的三种失败分支、引用计数

### 4. 不要动的东西

- 不要改 `contracts/` 下的任何文件
- 不要动 `frontend/src/api/` 里的生成代码
- 不要碰 `agent-runtime/`
- 不要为了这个切片新增任何依赖，如果你觉得需要，先告诉我

---

## 为什么必须这么写

AI 写代码的失败模式不是"写不出来"，是**在你没说清的地方自己编一个**。
编出来的东西单看没问题，跟别人的代码一拼就对不上。

上面四个部分正好堵住四个编造的入口：
- 缺"范围" → AI 顺手把相邻功能也做了，或者做一半
- 缺"契约" → AI 自己发明字段名和接口路径
- 缺"验收" → AI 只写 happy path，异常分支全是 `pass`
- 缺"不要动" → AI 去改公共文件，把别人的活覆盖掉
