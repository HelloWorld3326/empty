① 你要改哪些文件（nexent 侧，共 5 处前端改动）
  1. 新页面：frontend/app/[locale]/skill-opt/page.tsx —— 即上方原型的四个 Tab。参照仓库里 dify/datamate 外部服务集成页的写法（antd 6 + Tailwind，共用主题与布局）。
  2. 侧边栏菜单：frontend/components/navigation/SideNavigation.tsx 的 ROUTE_CONFIG 数组加一项 { path:"/skill-opt", Icon: Wrench, labelKey:"sidebar.skillOpt", order:… }。注意菜单会按数据库权限过滤 —— 权限 SQL 由后端（我）执行，你本地联调时可先用管理员角色。
  3. i18n：frontend/public/locales/zh/common.json 与 …/en/common.json 加 "sidebar.skillOpt": "技能优化" / "Skill Optimizer" 及页面内文案键。
  4. 服务层：新建 frontend/services/skillOptService.ts，端点注册进 frontend/services/api.ts。全部走 /api/skillopt/*，不需要处理鉴权头（server.js 网关自动注入 JWT）。
  5. 网关代理：frontend/server.js 加一条前缀规则：/api/skillopt/* → 环境变量 SKILLOPT_BACKEND（默认 http://nexent-skillopt:8600），转发时去掉 /skillopt 前缀。（两行级别，谁顺手谁做）

SkillOpt 服务本身、SQL 迁移、docker-compose 由后端负责，你不用管。

统一响应 {"code":0,"message":"ok","data":…}； code≠0 时直接 message.error(res.message)。关键错误码：40001 预检/参数失败（message 为可读原因，如缺 endpoint）、 40901 已有训练在跑（单任务限制，前端把「启动」按钮置灰并提示）、40401 不存在。

③ 状态机与轮询规则（前端唯一需要维护的状态）
idle 空闲→ 点启动（预检失败则留在表单页报错）→ running 运行中→ 自然结束 → finished 完成／点停止 → stopped 已停止／异常退出 → failed 失败
  • 监控页挂载时开始轮询 status + logs（各 2s，页面离开时清理定时器）；status.running=false 后再拉一次日志收尾，停止轮询。
  • 服务是单任务的：任何页面进入时先查一次 status，若 running 则「启动训练」置灰、监控页直接续上（刷新浏览器不丢——日志用 offset=0 全量拉一次再增量）。
  • 「已中断/失败」的任务再次以相同配置启动，训练会从断点自动续训（后端行为，前端无需特殊处理，可在文案上提示）。

  6. 用例 E：完成后结果页出现新 run，best_skill.md 可预览、可下载。
  7. 用例 F：运行中再点启动 → 40901 提示；刷新浏览器 → 监控页状态恢复。
