Mini Ontology Manager · 第一步

从底层表创建对象类型

这是 Ontology 成型的第一步：把一张原始数据表映射成业务对象 —— 选表、命名、挑属性、定主键和标题。左边是数据库眼里的"表"，右边的向导完成后，它就变成了业务眼里的"对象"。流程与 Palantir Ontology Manager 的 Create object type 向导一一对应。
