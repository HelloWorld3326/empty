从底层表创建对象与链接

Ontology 成型的前两步：先把原始数据表映射成业务对象（选表、命名、挑属性、定主键和标题），再用外键把对象之间的关系固化成链接 —— 从此查关联数据不再写 JOIN，点一下就能沿关系跳转。流程与 Palantir Ontology Manager 的向导一一对应。
