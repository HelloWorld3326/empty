Object 对象

现实世界里的一个实体：一位客户、一张订单。属于某个对象类型，有固定的属性表和唯一主键。

⇄

Link 链接

对象之间的关系，有类型、有方向、有基数（1:N、N:N）。查询不写 JOIN —— 沿着链接走就行。

↯

Action 操作

唯一的写入口。接收参数 → 校验规则 → 生成一组编辑 → 原子写回，并留下可追溯、可撤销的记录。
