# Vendored skills: mattpocock/skills

The skills in this directory are copied from
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT licensed),
pinned at commit `5b15a47f2d7150f545fbcacbfe381787fc0230dc` (v1.2.3).

They're plain files, not a plugin install, so they load automatically in any
Claude Code session on this repo — including Claude Code on the web — with
no marketplace or plugin setup step required.

## First-time setup

Run `/setup-matt-pocock-skills` once in this repo to configure the issue
tracker, triage labels, and domain-doc layout the other engineering skills
assume.

## Updating

These files are a snapshot, so they won't update automatically. To pull in
upstream changes, re-copy the relevant folders from the source repo (or run
`npx skills@latest add mattpocock/skills` and merge), then diff against what
you've customized here.

See the [upstream README](https://github.com/mattpocock/skills#readme) for
the full skill catalogue and descriptions.
